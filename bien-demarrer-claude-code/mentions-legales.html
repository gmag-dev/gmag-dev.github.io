Ce que l’hébergeur enregistre

Pour afficher une page, votre navigateur s’adresse aux serveurs de l’hébergeur.

GitHub indique enregistrer et conserver l’adresse IP de chaque personne qui visite un site GitHub Pages, à des fins de sécurité, qu’elle ait ou non un compte GitHub. L’adresse IP est le numéro qui identifie votre connexion à internet. Source : la documentation de GitHub Pages (en anglais), relue le 21 novembre 2026.

C’est GitHub qui tient ce journal, c’est-à-dire ce registre technique des visites.

GitHub est une société établie aux États-Unis. Elle indique conserver et traiter des données personnelles dans plusieurs pays, dont les États-Unis.

Sa déclaration de confidentialité (en anglais) dit ce qu’elle fait de ces données et comment lui écrire pour exercer vos droits. Elle donne aussi une adresse dans l’Union européenne : GitHub B.V., Prins Bernhardplein 200, 1097JB Amsterdam, Pays-Bas.
