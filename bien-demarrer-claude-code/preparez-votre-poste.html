Bien démarrer avec Claude Code, version 3.2.0+publique.web · 21 novembre 2026

Cette page vous sert si votre ordinateur est fourni par votre employeur ou par une autre organisation. Chez vous, sur votre propre ordinateur et avec votre propre compte, vous n’en avez pas besoin : la page « Prérequis » du guide suffit.

⚠️ Attention

Sur un ordinateur fourni par votre employeur ou par une autre organisation, n’installez rien de ce guide avant son accord : ni git, ni Python, ni Claude Code. Posez d’abord quatre questions à la personne qui gère le poste. Claude Code y est-il permis ? Avec quel compte ? Pouvez-vous installer vous-même un logiciel, Git for Windows et Python compris ? Le réseau de l’organisation demande-t-il un réglage, un proxy par exemple ? Ses règles passent avant ce guide (section 23.1 du guide). Des données de votre employeur ne passent que par le compte que votre organisation vous fournit pour cela, un compte commercial Team, Enterprise ou API : jamais par un compte que vous avez ouvert vous-même, ni par un abonnement Pro, Max ou Ultra, même payé par votre employeur. Qu’une installation passe sans droits d’administration ne veut pas dire qu’elle est permise. Si un installeur demande des droits que vous n’avez pas, si PowerShell refuse un script, ou si la connexion échoue sur le réseau de l’organisation, ne contournez rien : arrêtez-vous et posez la question.

💡 Conseil

Le message à transmettre à la personne qui gère votre poste, à copier tel quel :

Bonjour,
Je voudrais essayer Claude Code, l'outil d'Anthropic, avec un guide de prise en main. Avant d'installer quoi que ce soit sur mon poste, pouvez-vous me dire :
1. Claude Code est-il permis sur ce poste, et avec quel compte de l'organisation (Team, Enterprise ou API) ?
2. Puis-je installer moi-même git (Git for Windows sous Windows) et Python 3, ou devez-vous le faire ?
3. Le réseau demande-t-il un réglage, un proxy par exemple ?
4. Quelles données de l'organisation ai-je le droit de lui confier ?
Merci.
