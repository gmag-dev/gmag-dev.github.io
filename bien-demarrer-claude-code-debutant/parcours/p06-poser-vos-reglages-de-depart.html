P06 · Poser vos réglages de départ

Séance 2 · Étape 6 sur 15

Avant de continuer

Sans rouvrir l’étape précédente : en mode Manual, qu’est-ce que Claude fait sans vous demander votre accord ?

Voir la réponse

Il lit dans le dossier de travail, et lance certaines commandes qui ne font que lire. Avant la plupart des gestes qui modifient un fichier, lancent une commande ou joignent le réseau, il s’arrête et demande.

But

Faire démarrer chaque session en mode Manual, sans avoir à taper l’option de l’étape précédente.

Point de départ

Vous avez fini l’étape P05. Votre terminal est ouvert dans le dossier mon-essai, et Claude Code n’est pas lancé.

Geste

  1. Regardez si votre fichier de réglages personnels existe déjà. Il se trouve à l’adresse ~/.claude/settings.json, dans votre dossier personnel.

    cat ~/.claude/settings.json

  2. Ouvrez ce fichier.

    Windows, dans PowerShell (hors WSL)

    notepad $HOME\.claude\settings.json

    Si le Bloc-notes demande s’il doit créer le fichier, acceptez.

    macOS, Linux et WSL

    nano ~/.claude/settings.json

  3. Si le fichier est vide, écrivez-y ce contenu. Dans ce fichier, le mode Manual s’écrit « default ». S’il contient déjà des lignes, ce qui est courant après un premier lancement, ne les effacez pas : lisez d’abord, plus bas, « Le fichier contenait déjà des lignes ».

    {
  "permissions": {
    "defaultMode": "default"
  },
  "useAutoModeDuringPlan": false
}

  4. Enregistrez, puis fermez. Dans le Bloc-notes, par le menu Fichier. Dans nano, par Ctrl+O puis Entrée, et Ctrl+X.

  5. Lancez Claude Code, cette fois sans option. Il peut vous demander, une seule fois, s’il doit passer au mode auto : « Make auto mode your default permission mode? ». Le premier choix, « Yes, set auto mode as my default permission mode », est déjà surligné : n’appuyez pas sur Entrée. Descendez sur « No, keep manual mode », puis validez. En mode auto, Claude agit sans vous demander votre accord.

    claude

  6. Lisez la barre d’état, puis quittez par /exit.

Ce que vous devez voir

  • À la ligne 1, le contenu du fichier s’il existe, ou une erreur qui dit qu’il est introuvable. Les deux cas sont normaux.
  • À la ligne 6, la barre d’état affiche ⏸ manual mode on, sans que vous ayez tapé d’option.

Vérifiez vous-même

Relancez la ligne 1. Elle affiche maintenant vos deux réglages. Le second vous servira à l’étape P10 : il vous fait demander votre accord là où Claude Code déciderait seul.

🌉 Vous retrouvez le choix d’Inès à la permanence : le mode Manual, où Claude Code demande votre accord avant la plupart des modifications. Chez vous, il vaut désormais à chaque lancement, sauf dans un dossier qui porte ses propres réglages.

Si ce n’est pas ce que vous voyez

Le fichier contenait déjà des lignes

Claude Code y a noté un de vos choix, par exemple les couleurs de l’affichage. Gardez tout. Juste après la première accolade, sur une ligne nouvelle, ajoutez ces quatre lignes, virgule finale comprise. Si le fichier porte déjà une ligne « permissions », n’en ajoutez pas une seconde. Dans ce bloc, écrivez « default » après « defaultMode ». Si cette ligne n’y est pas, ajoutez-la juste après l’accolade du bloc, suivie d’une virgule. Ajoutez ensuite la dernière des quatre lignes, hors du bloc.

  "permissions": {
    "defaultMode": "default"
  },
  "useAutoModeDuringPlan": false,

Au lancement, Claude Code affiche une erreur de réglages

Le message contient Settings Error : le fichier porte une faute. Quittez, rouvrez-le par la ligne 2, et comparez ses accolades, ses guillemets et ses virgules au modèle. Aucune virgule ne suit la dernière ligne avant une accolade fermante.

La barre d’état annonce le mode auto

Elle affiche ⏵⏵ auto mode on : le mode auto a été accepté. Appuyez une fois sur Maj+Tab, la barre revient à ⏸ manual mode on. Quittez ensuite, rouvrez le fichier par la ligne 2, et écrivez « default » après « defaultMode ».

La barre d’état affiche autre chose

Le réglage n’a pas été lu. Relancez la ligne 1 : si elle n’affiche pas votre réglage, le fichier n’est pas à la bonne adresse. En attendant, lancez Claude Code par la commande de l’étape P05.

claude --permission-mode manual

Mise en garde

Lisez la barre d’état à chaque lancement. Sans réglage, Claude Code peut démarrer dans un mode qui demande moins souvent votre accord que le mode Manual. Votre réglage ne vaut que sur cet ordinateur, et le réglage d’un projet ou d’une organisation passe avant lui.
